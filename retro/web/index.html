Getting started

  1. Run the installer, then start EasyAmp from the Start Menu or the desktop icon. (Using the single file instead? Put it in a folder of its own, such as C:\EASYAMP, and run it.)
  2. Press +FILE, or drag music onto the window. It plays MP3, FLAC, Ogg Vorbis and WAV.
  3. Plex: open SOURCES and press +PLEX. EasyAmp shows a four-character code. On your phone, go to plex.tv/link and type it in. Your library then appears here.
    Your Plex server must allow plain local connections: Settings, Network, Secure connections = Preferred. That is the default.
  4. Jellyfin: press +JELLYFIN and type your server's address (like 192.168.1.5:8096), user name and password. The password is never saved.

What it needs

Windows 98 SE through XP. A Pentium II or Celeron and up. Any colour depth from 16 colours. A network connection only for Plex and Jellyfin. The clock does not have to be right.

What it is

A native Windows program written from scratch in C, for the machines that still run. Free and open source under the MIT licence, and it always will be. The full story, screenshots and source are on the modern web at www.easyampstereo.com/retro.html - open that one on a newer computer.
